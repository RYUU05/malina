# Malina App 🍓

Тестовое задание: приложение для заказа еды и бьюти-услуг. 
Сделано на Flutter. Постарался держать код чистым, разбил по фичам для удобства.

## Что внутри:
* **Авторизация**: Логика с хранением в SharedPreferences. Есть защита: 3 неверных входа — сброс данных.
* **Корзина**: Добавление, удаление, изменение количества. Сохраняется локально с дебаунсом (чтобы не дергать память на каждый клик).
* **Сканер**: QR-сканер (mobile_scanner) для быстрого добавления.
* **UI**: Кастомный BottomBar, анимированные вкладки в корзине, списки категорий.

## Стек:
* **State Management**: BLoC.
* **Навигация**: GoRouter.
* **DI**: GetIt.
* **Хранение**: SharedPreferences.
* **Модели**: Freezed.

## Как запустить:
1. `flutter pub get`
2. `dart run build_runner build`
3. `flutter run`

## Структура проекта:
* `lib/core` — общие штуки (роутер, DI, виджеты).
* `lib/features` — логика по фичам. Внутри каждой фичи: `bloc`, `presentation` и репозиторий с моделями. Так проще ориентироваться.
